# Contributing

Include a minimal synthetic example with a proposed fix. Run the panel tests and demo before submitting changes. State how a modeling change alters the estimand, sample, exposure definition, or inference. Preserve historical sources and attribution; implement new functionality outside `legacy/` and `upstream/`.

Do not upload research data, confidential correspondence, credentials, restricted geospatial files, or large binaries. A data-dependent issue should describe the schema and use anonymized synthetic records. Changes claiming causal identification should include the institutional argument and diagnostic plan, not just a significant coefficient.
